# ⚡ Klyde Joseph | Professional Automation Portfolio

A high-end, responsive portfolio built with **Streamlit** and **Python**. This application features glassmorphism UI design, CSS3 animations, and integrated Lottie animations to showcase automation projects and IT expertise.

## 🚀 Features
- **Dynamic Navigation:** Multi-page experience (Home, Projects, Resume, Contact).
- **Glassmorphism UI:** Modern frosted-glass aesthetic using custom CSS injection.
- **Project Grid:** Automated layout for showcasing GitHub repositories.
- **Asset Integration:** Base64 encoding for local images (IDs and Resumes) to ensure cloud compatibility.
- **Interactive Forms:** Built-in contact inquiry system with success feedback.

---

## 🛠️ Tech Stack
* **Frontend/Hosting:** [Streamlit](https://streamlit.io/)
* **Language:** Python 3.9+
* **Styling:** Custom CSS3 & Google Fonts (Outfit)
* **Animations:** [LottieFiles](https://lottiefiles.com/) via `streamlit-lottie`
