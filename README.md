# 🚀 Modern Portfolio & Digital Journal (2026)

Welcome to my professional space! This project is a high-performance, Python-based portfolio built to showcase my work in web development, AI integration, and digital creation.

## 🛠 Tech Stack

- **Frontend/Backend:** [Streamlit](https://streamlit.io/) (Python-based framework)
- **Styling:** Custom CSS with a focus on "Bento Grid" UI/UX
- **Deployment:** Streamlit Community Cloud
- **Version Control:** Git & GitHub

## ✨ Key Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Interactive Projects:** A curated list of my latest work with live links.
- **Micro-Blogging:** A built-in blog section for sharing technical insights.
- **Professional Contact Form:** Integrated user feedback system.
